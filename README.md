# bible-notes-voice

This repository hosts the natural voice that the **bible_notes** iPhone app
downloads for reading the Bible aloud. The app reads with the phone's own voice
right away; when the reader asks for the natural voice, the app downloads it
once from this repository's Releases, checks it, and keeps it on the phone for
use without internet.

There is no code here. The files are in this repository's
[Releases](../../releases):

- `voice-manifest.json`: what the app reads first. It lists the pack's
  download URL, exact size in bytes, SHA-256, unpacked size, languages and
  license. The app always asks for the copy attached to the latest release
  (`releases/latest/download/voice-manifest.json`).
- `supertonic3-int8-v1.zip`: the voice itself. Inside, `pack.json` lists
  every file with its SHA-256 and size.

## The model

The voice is **Supertonic 3**, a text-to-speech model by **Supertone Inc.**,
from https://huggingface.co/Supertone/supertonic-3. It is licensed under the
BigScience **Open RAIL-M** License; the full text is in [LICENSE](LICENSE).
The model comes with use restrictions that apply to anyone who uses it; they
are summarized in [NOTICE.md](NOTICE.md), and the license text is what counts.

The files in the download were modified: the model's large weights are stored
as 8-bit integers and turned back into float32 inside the model when it runs,
which makes the download about four times smaller than the original (95 MB
instead of 398 MB). NOTICE.md lists exactly what changed. Supertone and Supertonic are names of Supertone Inc.;
they are used here only to say where the model comes from.

The voice is synthetic. Every voice in the download is generated by a
computer; none is a recording of a person reading.

## How a release is made

A script rebuilds the zip from the official files, pinned to one Hugging Face
revision and verified by SHA-256, and writes the manifest. The zip is
deterministic (sorted entries, fixed timestamps). A new voice or a new
precision is a new pack id or version and a new release; old releases stay
so that installed copies can still be checked.
