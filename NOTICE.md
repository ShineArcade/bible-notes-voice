## What was changed

The original model files are float32. In this copy the large weights of the
files below are stored as 8-bit integers and turned back into float32 inside
the model when it runs, which makes the download about four times smaller.
The architecture, the inputs and outputs, and every other value are
unchanged.

- `onnx/text_encoder.onnx`: 45 weight tensors (8,946,176 values) stored as int8 with one float32 scale per output channel.
- `onnx/vector_estimator.onnx`: 96 weight tensors (63,750,144 values) stored as int8 with one float32 scale per output channel.
- `onnx/vocoder.onnx`: 23 weight tensors (25,251,840 values) stored as int8 with one float32 scale per output channel and block of 32 input channels.

Each changed `.onnx` file says the same in its own metadata
(`modification_notice`). `onnx/duration_predictor.onnx`, `onnx/tts.json`, `onnx/unicode_indexer.json`
and every file in `voice_styles/` are unchanged copies of the originals.
